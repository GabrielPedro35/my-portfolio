# Project

Gabriel's web designer portfolio (fork of dillionverma/portfolio).

- Stack: Next.js 16.1.1, React 19, Tailwind CSS v4, TypeScript, content-collections, shadcn/ui, Magic UI
- Package manager: pnpm (lockfileVersion 9)
- Config: `src/data/resume.tsx`
- Scripts: `pnpm dev` / `pnpm build` / `pnpm start` / `pnpm lint`
